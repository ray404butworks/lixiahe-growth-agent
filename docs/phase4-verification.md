# 阶段四 · 经营报告交付验证

## 验收路径

1. 导入「正常经营」合成样例，确认映射并进入看板。
2. 进入经营诊断，生成建议，再从建议卡片进入营销方案。
3. 选择商品，核对事实并生成营销草稿。编辑商品文案后点击「查看经营报告」。
4. 检查当前筛选范围、证据键、已编辑草稿、来源和七日行动清单。
5. 下载 Markdown、HTML 和汇总 CSV。点「打印 / 保存 PDF」，在浏览器中选择保存为 PDF。
6. 回到看板切换销售渠道，再看报告，确认旧诊断和旧草稿已经移除。

导出在浏览器完成。CSV 保留完整渠道、商品和日期分组，缺失值留空。页面和打印报告的渠道、商品表最多展示 12 项。报告附带合成数据标记、财务口径与发布前复核提示。
