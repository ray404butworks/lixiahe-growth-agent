# 订单数据契约 v1.0

每行代表一个订单中的商品行。订单级运费、平台费、广告费必须先分摊到行。
仅映射后的13个经营字段进入指标计算；原文件留在当前浏览器内存，不写入数据库或浏览器持久存储。

| 字段 | 必需 | 规则 |
|---|---|---|
| order_date | 是 | YYYY-MM-DD、YYYY/M/D、ISO时间或1900系统Excel序列；按标注日期归属，不换算时区 |
| sku / product_name / channel | 是 | 非空；分别不超过100/200/100字符 |
| quantity | 是 | 大于0，最多18位整数和8位小数 |
| unit_price | 是 | 非负，最多18位整数和8位小数 |
| order_id | 建议 | 缺失则不报告订单数、客单价；不把行号冒充订单ID |
| unit_cost | 建议 | 单位进货成本；空白未知 |
| shipping_cost / platform_fee / ad_cost | 建议 | 该行实际费用；空白未知，填写0代表确实没有 |
| refund_amount | 建议 | 非负且不超过该行成交额；只有显式确认才将空白按0处理 |
| order_status | 建议 | paid/refunded/cancelled；空白只有显式确认才按paid处理 |

中文状态白名单：已支付、已完成、交易成功；退款、已退款、部分退款；取消、已取消、交易关闭。
不猜测“待发货”“售后中”等平台状态，请在导入前转换成明确状态。
序列60对应不存在的1900-02-29，拒绝。未格式化的纯数值序列按1900系统解读；1904系统请导出为ISO日期。
表头存在多个同义候选时不自动匹配，需人工选择；同一源列不可映射到多个字段。

## 金额与期间

数量与单价各转换成10^8整数，乘积保持10^16精度。汇总使用BigInt，JSON保留十进制字符串；仅展示四舍五入到分。
贡献率及均值保留8位小数，绘图仅在最终展示时转换为Number，不用于账本。
成交额=Σ数量×单价；扣退款销售额=成交额−退款；可变成本=Σ数量×单位成本+运费+平台费+广告费。
只有退款和全部四项成本完整才展示贡献毛益；任何汇总组均独立判断完整性，不混用部分成本推算利润。
贡献率分母为0则不可计算。没有可靠订单ID时只提供行均金额，不提供客单价。
取消单不参与指标；退款单保留费用。重复订单ID可能是多商品行：金额不自动去重，订单数按ID去重，同时提示风险。
退款按订单日而非实际退款发生日归属，因此不是现金流或到账收入。没有固定成本、税费，不得称净利润。
日期筛选为闭区间；最后7个日历日与此前7日比较，覆盖不满14日不显示增长率。上期0则“新产生/不可比较”。

## 边界

CSV/XLSX最大5MiB、10,000行、100列；XLSX解压总量不超过25MiB、最多2000个ZIP成员，不支持加密文件和ZIP64。
错误行带原始数据行号、字段和原因。含错误行时需勾选确认，才可仅分析有效行。不会悄悄删除或填0。
阶段二为浏览器本地计算，尚无账户、数据库持久化或多租户权限。未来服务端接入须复用同一纯函数并再次校验输入。
