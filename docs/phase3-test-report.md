## 本阶段覆盖

- 无数据时阻止诊断；六张知识卡可独立查看。
- 服务端重算指标，证据引用存在且数值由服务器渲染；缺成本不输出利润。
- 空Key、未允许、超时、网络/认证错误、无效JSON、虚构来源、数字冲突降级规则；非法输出最多两次传输。
- 模型每日尝试次数限制、5分钟缓存、跨站拒绝、请求字段与大小检查。
- 商品事实逐项确认；未确认保持待核对；拦截未审核的受保护名称、认证、疗效与极限宣称。
- 生成三类可编辑草稿及七日清单；复制保留标记、来源与核对项。
- 修改筛选、商品事实、建议或清除会话后旧内容失效；请求期间修改事实不被旧响应覆盖。
