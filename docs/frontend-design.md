# 前端简化约定

这一批覆盖导入首屏、共用导航、页面标题和看板摘要。沿用 Next.js、现有图标、原生控件和现有处理函数。

| 决定 | UX | DX | AX |
| --- | --- | --- | --- |
| 六个入口，图标配名称 | 扫一眼即可定位任务 | 一份导航配置供桌面和手机共用 | 保留导航地标、当前页状态和明确按钮名 |
| 页标题直接写任务 | 减少重复阅读 | 页面文案集中维护 | 标题层级可定位当前任务 |
| 上传优先，三个样例并列可选 | 两种开始方式同屏 | 复用原上传和样例函数 | 原生文件输入与稳定的样例操作名 |
| 模板和解析参数收在原生折叠项 | 需要时再展开 | 无新状态、无新依赖 | 原生展开状态与有标签的表单控件 |
| 指标数值优先，口径集中展开 | 首屏更短，保留核对依据 | 四项指标共用一份显示配置 | 数值、定义和缺失原因保留语义结构 |
| 缺失字段、错误、演示标识保持可见 | 避免误判和误操作 | 沿用校验结果 | 不隐藏阻断状态或数据来源 |

## 后续约束

- 一页一个明确任务；主按钮使用动作名称。
- 不用标语、开发阶段、装饰标签补救布局。
- 颜色与表面在 workspace.css 定义，页面只处理布局差异。
- 改版保留接口契约、计算口径、模型授权开关和所有功能入口。
- 真实模型默认不启用；仅用合成样例验收。
- 每批先验收桌面与手机，再推广到其他页面。

## 已确认

- 经营页采用 A 版信息密度，作为后续页面基准。
- 空状态只保留当前缺口和可执行动作；无导入数据、无有效交易、缺少诊断分别处理。
- 回到筛选不清除数据；使用样例仍经过字段核对和确认导入。

## 页面文案

- 前端不显示开发来源署名和反复免责的段落；开源归属随 LICENSE、UPSTREAM.json 保留。
- 来源、指标依据和可执行动作直接呈现；待补字段与操作错误保留。
- 用正向条件、公式和状态说明规则，避免“不证明、不代表”式长句。
