# 阶段一、二开发基线

依据2026-11-04计划书v1.0，采用14天标准P0范围。本交付只覆盖此前约定的基础适配与可信分析阶段。

## 阶段一：基础适配

- 在CSV AI Analyzer固定提交上修改，保留原MIT版权、工作区库、CSV/XLSX解析和Docker配置。
- 中文工作台、导入页、看板页；三种960行农品合成样例；CSV与Excel模板。
- 样例商家与交易始终明确标为虚构，产品名称不作为产地认证。

## 阶段二：可信分析

- CSV编码/分隔符、XLSX工作表选择、源列与13个字段映射。
- 校验、缺失统计、重复ID风险、异常行确认剔除、极端值提示、日期范围。
- 销售额、唯一订单数/行均口径、销量、贡献毛益/贡献率；日期/渠道筛选；日趋势、渠道对照、商品排名。
- 财务纯函数、独立手算测试、导入边界测试和浏览器流程检查。
- 指标JSON可下载供复核。正式经营报告和营销内容不属于本阶段。
